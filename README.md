# coffee-shop-management-system-cpp
A C++ based Coffee Shop Management System with login/register functionality, order processing, billing system, and admin panel using file handling.

## 🎓 University Project Report

A fully functional **console-based Coffee Shop Management System** developed in **C++**.  
This project demonstrates practical implementation of **Object-Oriented Programming (OOP)**, **file handling**, and **menu-driven system design**.

It simulates a real-world coffee shop workflow including user authentication, order processing, billing system, and administrative controls.

---

## 📌 Project Objectives

- To design a real-world business management system using C++
- To implement secure user authentication (Login/Register)
- To manage coffee shop orders efficiently
- To calculate bills with discount logic
- To apply file handling for data persistence

---

## ✨ Key Features

### 👤 User System
- User Registration system
- Secure Login authentication
- Role-based access (Admin/User)

### ☕ Coffee Shop Operations
- Dynamic coffee menu display
- Order placement system
- Quantity-based billing system
- Automatic total calculation

### 💰 Billing System
- Item-wise billing
- Total price calculation
- Discount system for large orders

### 🧑‍💼 Admin Panel
- View menu items
- Add new items to menu
- Manage product list

### 💾 File Handling
- Persistent user storage using text files
- Data retention after program restart
